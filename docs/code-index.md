# cueq Code Index

Status: initial directory-first source inventory before cleanup/refactor.

Method: inspected repository command surfaces, source tree, high-risk runtime
files, package boundaries, contracts, and representative UI/API/domain modules.
Build outputs under `dist/`, `.next/`, `.turbo/`, and package-local
`node_modules/` artifacts are excluded as generated/cache output.

The repo currently has about 386 meaningful non-build files across source,
tests, scripts, schemas, fixtures, contracts, migrations, and CI/config. This is
too large for trustworthy deep file-by-file semantic inspection in one pass, so
this index is directory-first. Central and high-risk files are indexed
individually; large repeated areas are represented by directory with the exact
files that need deeper inspection listed in the coverage section.

## Runtime Map

- API entrypoint: `apps/api/src/main.ts` starts NestJS, Helmet, CORS, global
  Prisma/Zod filters, and non-production Swagger/OpenAPI.
- API module root: `apps/api/src/app.module.ts` wires Prisma, auth, scheduler,
  health, and the large operational `Phase2Module`.
- Operational API module: `apps/api/src/phase2/phase2.module.ts` registers most
  controllers, domain services, workflow helpers, terminal import, HR import,
  closing, roster, reports, webhooks, and policy services.
- Web entrypoints: `apps/web/src/app/layout.tsx`,
  `apps/web/src/app/page.tsx`, `apps/web/src/app/[locale]/layout.tsx`, and
  localized pages under `apps/web/src/app/[locale]/*/page.tsx`.
- Domain packages: `packages/core/src/index.ts`,
  `packages/policy/src/index.ts`, `packages/shared/src/index.ts`, and
  `packages/database/src/index.ts`.
- Storage contract: `packages/database/prisma/schema.prisma` plus migrations.
- Public API contract: `apps/api/src/openapi.ts`,
  `apps/api/src/openapi-export.ts`, `scripts/export-openapi.mjs`, and
  `contracts/openapi/openapi.json`.
