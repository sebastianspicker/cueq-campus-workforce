## Refresh the tour

Build and serve the demo using its [preview instructions](../../demo/README.md).
Open each route at the dimensions above and reload to restore the initial
records. Wait for the page to render and any notification to disappear, then
capture the viewport.

Check that text is readable, nothing is clipped, and no unrelated tabs or
personal information are visible. Keep the filenames above so README links
continue to work. The demo uses no signed-in session, API, or database.
